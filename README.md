# SARAH LAUREN — website

A static, GitHub Pages-compatible website for Sarah Lauren, Artist & Creative House.

## Publish

Upload the contents of this `sarah-lauren` folder to the root of the GitHub Pages repository. Keep the relative folder structure intact.

## Before publishing

1. Open `js/data.js` and set `EMAIL` to the studio email address you want enquiries sent to. This activates the artwork enquiry and collaboration links.
2. Review artwork titles, dimensions, dates and availability in `js/data.js`. The site currently uses the supplied artwork descriptions and intentionally does not invent titles or commercial availability.
3. Check the About copy and copyright wording before launch.

## Structure

- `index.html` — page content and metadata
- `css/style.css` — visual system and responsive layouts
- `js/main.js` — artwork viewer, navigation, reveal effects and contact links
- `js/data.js` — artwork records and contact email configuration
- `assets/images/` — supplied artwork, detail photography, favicon and social image
- `assets/video/process.mp4` — supplied process video

The site uses plain HTML, CSS and JavaScript. Google Fonts are loaded remotely; system fallbacks are included.
